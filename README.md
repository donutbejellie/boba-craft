# Boba Craft

A simple bubble tea UI made with HTML5, CSS, and JavaScript.

## What's Inside
- 6 teas you can click to customize
- A cart drawer
- A boba splash pad game at the bottom

## How to Run
Put `index.html`, `index.css`, and `index.js` in the same folder and open `index.html` in your browser.
